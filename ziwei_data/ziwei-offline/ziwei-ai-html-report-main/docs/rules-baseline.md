# 规则基线（自包含）

本文为 `ziwei-ai-html-report` 的本地规则基线，不依赖仓库外文档。

## 1. 历法与时间口径

- 派别：中州派
- 分年：正月初一分年
- 换日：23:00 视作晚子时换日
- 真太阳时：默认启用，固定 UTC+8（120E），不回溯历史夏令时

## 2. 排盘算法要点

- 命宫：月顺时逆
- 身宫：月顺时顺
- 十二宫：逆布
- 五行局：水二、木三、金四、土五、火六
- 紫微定位：按农历日与局数换算
- 主星：紫微系 + 天府系十四主星
- 辅煞：左右昌曲魁钺、禄存羊陀、火铃空劫、天马
- 四化：十干四化表
- 运限：阳男阴女顺，阴男阳女逆

## 3. 语义与输出要点

- 主星语义：采用 `tools/knowledge_semantics.json` 中结构化描述
- 宫位语义：采用 `tools/knowledge_semantics.json` 的宫位要点
- 格局提示：采用 `pattern_rules` + `pattern_rule_sources`
- 输出必须含免责声明与“仅供参考”说明

## 4. 可靠性交付护栏

- 命盘结构必须 12 宫
- 必须包含五行局、本命四化、流年块
- K 线必须 100 条、年龄 1-100 唯一、OHLC 关系合法、open 连续
